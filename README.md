A make.fun entry for **One-Line Office Jokes** — one single line that makes office life funny.

## The line

> My calendar is so full that my lunch break now has a waitlist, and I'm third in line for my own sandwich.

## How it works

`main.py` (Python standard library only) writes the line to `/output/entry.txt`. It includes a `validate()` gate mirroring the bounty gate: UTF-8 text, 1–199 characters, a single line, not only white space.

```sh
python3 main.py
cat /output/entry.txt
```
